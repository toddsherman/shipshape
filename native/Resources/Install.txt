Shipshape 0.3.26 — macOS preview

Requires macOS 13 or later. Includes Apple silicon and Intel binaries.

To install
Drag Shipshape into Applications, then open it from Applications.
Add the folders that hold your projects, run the first check, and enable
notifications. In Settings you can also start the app when you log in.

What it checks
Runtimes, package managers, AI coding tools, MCP servers, Homebrew
libraries, developer apps and your projects' dependencies, against OSV,
NVD and vendor advisories, including reports of malicious packages.
Each finding shows the installed and fixed versions, its evidence and the
easiest way to install the fix: a Terminal command to copy, a download
page, or the app's own updater. The app never runs commands or changes
other software itself.

Inventory also shows how each app is signed, for your information:
which apps are ad-hoc signed, unsigned or without the Hardened Runtime.
Apps built on your Mac and some Homebrew casks are ad-hoc signed by
design, so these aren't findings.

A fresh check runs each time the app opens, daily at 9 a.m. Pacific while
the app is running, and when you click Check now. Missed checks catch up
after wake. History logs every recommendation and when it was resolved.
Closing the dashboard leaves Shipshape running in the menu bar and the
Dock; click either to open it again. Quit in the Dock also keeps it in
the menu bar. Quit in the menu bar panel, or Command-Q, stops monitoring.

Coverage is partial
Google Chrome and App Store apps are not checked; they update through
Chrome's own updater and the App Store.
Vulnerabilities in editor extensions, CocoaPods, container images,
software outside the built-in catalog and arbitrary install paths are
not checked. This is not a
malware scan or a guarantee of safety.

Privacy
Each Mac keeps its own inventory in:
~/Library/Application Support/Shipshape
Package names and versions, including private package names from your
lockfiles, are sent to OSV; product versions are sent to NVD; self-updating
apps' update feeds are fetched from their developers. MCP
settings are read for server commands only, never keys or environment
variables. No account or API key is needed. Exported reports include
local paths and package names.

Updates
Shipshape checks for a new version of itself once a day. It shows the
release notes; Install Update downloads it, checks that it's signed by
Shipshape's developer, then quits, replaces and reopens the app. Nothing
is installed until you click. The daily check can be turned off in Settings.

To uninstall, turn off Start at login, quit the app, and move
it to Trash. Its Application Support data can be removed separately.
